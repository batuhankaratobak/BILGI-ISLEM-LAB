# Güvenlik Sınırları

Bu lab öğrenme amaçlıdır ve üretim ortamı değildir.

Kurallar:

- Gerçek şifre, DSRM secret, token, key veya kişisel veri commit edilmez.
- ISO, VHD/VHDX, VM runtime dosyaları Git'e eklenmez.
- DHCP sadece internal switch üzerinde tutulur.
- GLPI ve MySQL internete açılmaz.
- Kısıtlayıcı GPO'lar önce test OU üzerinde denenir.
- Yetkiler kullanıcılara değil gruplara verilir.
- Least privilege prensibi uygulanır.
