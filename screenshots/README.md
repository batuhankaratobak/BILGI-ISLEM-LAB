# Ekran Görüntüsü Kontrol Listesi

Önerilen kanıt görselleri:

- Hyper-V VM listesi ve final checkpoint'ler
- DC01 Server Manager / rol durumu
- Active Directory kullanıcı ve grup yapısı
- DNS ve DHCP doğrulaması
- CLIENT01 domain join kanıtı
- Group Policy uygulama çıktısı
- Dosya paylaşımı erişim testi
- GLPI ticket listesi ve çözülmüş ticket ekranı
- PowerShell sağlık kontrolleri

Commit etmeden önce şifreleri, token'ları, anahtarları, kişisel host verilerini ve ilgisiz kişisel bilgileri kırpın veya redakte edin.

Yayına hazır kanıt seti `screenshots/evidence/` klasöründedir.
