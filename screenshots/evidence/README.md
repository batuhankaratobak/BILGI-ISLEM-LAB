# Kanıt Ekran Görüntüleri

Bu ekran görüntüleri GitHub yayını için kırpılmış ve gözden geçirilmiştir. Şifre, token, ISO dosyası, VM diski veya kişisel host yolu içermez.

| Dosya | Kanıt |
|---|---|
| `01-ad-users-department-ous.png` | AD kullanıcılarının departman OU'larına yerleştirilmesi |
| `02-file-share-access-denied.png` | IT kullanıcısının IT paylaşımına erişip HR paylaşımından reddedilmesi |
| `03-helpdesk-user-created.png` | Helpdesk kullanıcısının `BK-Helpdesk` grubunda olması |
| `04-helpdesk-password-reset.png` | Helpdesk hesabıyla test kullanıcısı şifresinin sıfırlanması |
| `05-password-reset-restored.png` | Test kullanıcısının şifre durumunun geri alınması |
| `06-services-dhcp-dns-health.png` | AD/DNS/DHCP servisleri ve DHCP scope doğrulaması |
| `07-dcdiag-admin-check.png` | Yükseltilmiş domain controller tanılama çıktısı |
| `08-final-hyperv-checkpoints.png` | DC01 ve CLIENT01 final Hyper-V checkpoint'leri |
| `09-glpi-ticket-list.png` | GLPI ticket kuyruğu ve lab incident/request listesi |
| `10-glpi-ticket-resolved.png` | GLPI ticket çözüm ve kabul ekranı |
| `11-client-domain-joined.png` | CLIENT01'in `bklab.local` domain'ine katılması |
| `12-password-policy.png` | Domain parola ve hesap kilitleme politikası doğrulaması |

Yeni ekran görüntüsü eklemeden önce ilgisiz UI alanlarını kırpın; kişisel isimleri, yolları, şifreleri, token'ları ve ilgisiz hesap detaylarını redakte edin.
